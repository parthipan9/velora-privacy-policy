Privacy Policy — Velora PinBot

Effective date: November 12, 2026

Velora PinBot is a personal-use Pinterest content creation and scheduling tool operated under the Velora name. This policy describes the tool's intended data handling. The tool is currently in development and is not offered as a public service.

Information accessed

When the operator authorizes Pinterest API access, the tool may access the operator's Pinterest account identifier, boards, Pins, and publishing information needed to create and manage approved content. The tool does not request access to other Pinterest users' private data.

How information is used

Account information is used only to authenticate API requests, select the operator's board, publish content that the operator has reviewed and approved, and record publishing results. It is not sold or used for third-party advertising targeting.

Storage and security

The tool is intended to store Pinterest API credentials as GitHub Actions secrets, not in source code. Publishing history may be recorded in a private GitHub repository. GitHub and Pinterest process data according to their own terms and privacy policies. No system can guarantee absolute security.

Sharing

The operator does not intentionally sell or share Pinterest account data with data brokers. Information necessary to operate the tool may be processed by Pinterest, GitHub, and any hosting provider configured by the operator.

Retention and deletion

Credentials can be revoked through Pinterest and removed from GitHub Actions secrets. Publishing history can be removed from the private repository by the operator, subject to GitHub's backup and retention practices.

Children's privacy

Velora PinBot is not intended for children under 13 and does not knowingly collect children's personal information.

Changes

This policy may be updated when the app's features or data practices change. The effective date above will be revised for material changes.

Contact

For privacy questions, contact the operator through the Velora profile.

This policy describes the planned personal-use tool; it should be reviewed and updated before expanding to public users or adding new data integrations.
